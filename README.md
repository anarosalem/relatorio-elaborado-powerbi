# Relatório Elaborado - Power BI (Sample Financials) 📊

## Objetivo
Este repositório contém a entrega do desafio de criação de um relatório interativo e elaborado no Power BI, utilizando a base de dados *financials*.

## Elementos Desenvolvidos no Relatório
O arquivo `.pbix` anexado neste repositório contempla todos os requisitos solicitados no desafio:
- ✔️ **Estrutura de Layout:** Fundo e disposição de elementos organizados.
- ✔️ **Navegabilidade:** Botões configurados para transição entre a Página 1 e a Página 2.
- ✔️ **Filtros e Interatividade:** Segmentadores de dados aplicados e associados a imagens.
- ✔️ **Indicadores (Bookmarks):** Utilização de botões e indicadores para alternar entre diferentes visuais sobre o mesmo assunto no mesmo espaço.
- ✔️ **Páginas:** O relatório final é composto por duas páginas completas.

## ⚠️ Observação sobre a Publicação (Power BI Service)
Conforme orientado nas instruções, o ideal seria publicar o relatório no Power BI Service. No entanto, como não possuo acesso a uma conta corporativa ou de estudante (requisito da Microsoft para o serviço online), **a entrega está sendo realizada unicamente através do arquivo físico (.pbix)**.

## Como visualizar o projeto
Basta fazer o download do arquivo `.pbix` contido neste repositório e abri-lo diretamente no **Power BI Desktop**.
